# Panduan AquaFlow v2 — Konsep Integrasi IoT × ML

Panduan terbaru ada di **[README.md](README.md)**. Untuk serah-terima kelompok, baca berurutan:

1. `docs/05_Audit_Perubahan.md` — audit perubahan dari ZIP buatan Aan.
2. `docs/03_Alur_Integrasi.md` — tiga flowchart software dan data antarplatform.
3. `docs/01_Tim_Hardware.md` — kontrak pembacaan ESP32, float switch, servo/pompa.
4. `docs/02_Tim_ML.md` — kelas model, feature contract, hasil training yang harus diserahkan.
5. `docs/04_Rencana_Uji.md` — skenario pengujian UAS dan batasan versi konsep.

Jalankan `npm start` lalu buka http://127.0.0.1:4173 untuk melihat dashboard simulasi. Tidak perlu npm install. Semua label pada demo adalah **contoh**, bukan prediksi ML hasil training.
